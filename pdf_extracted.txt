Technical Design Document: 
Daily Digest for Encounter Task Reviews 
Author: Meghana  |  Date: August 26, 2026  |  Status: Approved for Implementation 
Target Environment: Sandbox (allianceortho--stage) / Production (Alliance Prod) 
1. Executive Summary 
This document specifies the technical architecture, business logic, and deployment strategy for replacing 
individual, real-time email alerts with a unified End-of-Day Daily Digest Email for Managers and Team 
Leads. 
Currently, whenever an Encounter__c reaches 3 completed non-admin tasks, an immediate email is fired to 
the respective manager or team lead. In Production, with ~6,000 completed tasks processed daily, this 
generates ~110 to 125 individual email notifications per day, causing inbox fatigue and notification noise. 
The Solution: Implement a Scheduled Batch Apex Job that runs daily at 6:00 PM EST, aggregates all 
qualifying encounters completed that day by team members, and sends a single, consolidated HTML digest 
table to each respective Manager/Team Lead.

4. Business Logic Parity with Existing Flow 
The Scheduled Apex solution preserves 100% of the business logic, role hierarchies, and exclusion rules 
built into the current Flow: 
1. Admin Exclusion: Excludes all tasks created/modified by active System Administrators (Profile.Name = 
'System Administrator'). 

=== PAGE 3 ===
2. Task Count Threshold: Identifies encounters with >= 3 completed non-admin tasks. 
3. Duplicate Prevention: Only evaluates encounters where Manager_Notified__c = false. 
4. Role Routing Matrix: 
   • AR Specialist / Team Lead: Finds Parent Role. 
   • Offshore Roles: Standard Parent Role mapping. 
   • Conservative, Medical, Surgical, PIP: Climbs two levels up (Team Lead -> Group Lead -> Manager). 
5. Encounter Flagging: Flags Manager_Notified__c = true after the email digest is sent.

7. Deployment & Scheduling Guide 
Step 1: Deploy Required Metadata 
1. Deploy Field: Encounter__c.Manager_Notified__c (Checkbox, Default: False). 
2. Deploy Apex Classes: EncounterDailyDigestBatch.cls and EncounterDailyDigestBatchTest.cls, 
EncounterDailyDigestScheduler, EncounterDailyDigestSchedulerTest. 
3. Deactivate Old Flow: Deactivate Send_Notification_To_Managers_TeamLeads in Production. 
Step 2: Schedule the Daily Batch Job 
Execute the following one-line anonymous Apex command or use the Salesforce UI (Setup -> Apex Classes 
-> Schedule Apex): 
// Schedules the Digest to run daily at 6:00 PM EST (Monday to Sunday) 
System.schedule( 
    'Daily Encounter Task Review Digest',  
    '0 0 18 * * ?',  
    new EncounterDailyDigestBatch() 
);
